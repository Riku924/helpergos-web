# 船あさり / 難破船カード (Shipwreck)

## 概要
ゲーム開始時に全員へ配られ、ゲーム中は「船あさり」アクションで追加取得できるカード群。

## ゲーム開始時の初期配布

- 54枚全てをよく混ぜ、裏向きで配る。
- 残りのカードは山札として場に置く（船あさりアクションで引く）。

| 人数 | 1人あたりの枚数 |
|------|--------------|
| 3〜8人  | 4枚 |
| 9〜12人 | 3枚 |

## 船あさりアクション

- 釣り・水汲み・伐採と同列の**アクション**の1つ。
- 1ターンに選べるアクションは1つだけ。
- 山札の一番上から1枚を引き、手札に加える。
- **他のプレイヤーには見せてはいけない**。

### 山札切れ
- 山札がなくなった場合、全カードを再構築してシャッフルし再利用する。
