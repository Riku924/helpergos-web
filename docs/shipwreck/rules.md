# 船あさり / 難破船カード (Shipwreck)

## 概要
難破船に乗り込んでカードホルダーから1枚引くアクション。  
引いたカードは手札として秘密保持する。

## ルール

### アクションとしての位置づけ
- 釣り・水汲み・伐採と同列の **アクション** の1つ。
- 1ターンに選べるアクションは1つだけ。

### 手順
1. 難破船カードの山札から**一番上の1枚**を引く。
2. 引いたカードを**手札**に加える。
3. **他のプレイヤーには見せてはいけない**。

### 山札切れ
- 山札がなくなった場合、使用済みカードをシャッフルして再利用する。
