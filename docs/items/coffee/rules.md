# コーヒー (Coffee)

## 概要
難破船カードの1種。今の手番に追加でもう1回アクションできるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | コーヒー |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 今の手番にアクションをもう1回追加で実行できる |

## ルール

### 使用方法
- 自分の手番中に使用を宣言する。
- 使用後、通常のアクション（釣り・水汲み・伐採・船あさり）をもう1回選んで実行できる。
- 使用後は手札から捨てる（1回限り）。

### 使用タイミング
- **アクションの代わりに使う**のではなく、アクションに**加えて**使う。
- コーヒーを使用した手番の追加アクション1回分として機能する。
- 追加アクションでもう一度コーヒーを使うことはできない（1手番に1回限り）。

### 具体例
1. コーヒーを宣言 → 釣りを実行（追加1アクション）
2. コーヒーを宣言 → 伐採を実行（追加1アクション）
3. コーヒーを宣言 → 水汲みを実行（追加1アクション）

## 使用タイミング（実装予定）

手番中のアクション実行前に「コーヒーを使う」ボタンを表示する。  
使用すると `G.extraActionThisTurn = true` フラグを立て、  
通常アクション実行後にもう1回アクションを選べる状態にする。  
追加アクション完了後、フラグをリセットしてターン進行。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
