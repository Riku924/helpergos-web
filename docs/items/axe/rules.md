# 斧 (Axe)

## 概要
難破船カードの1種。伐採アクション時に森の入り口で持ち帰れる木材を2本にする装備カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 斧 |
| デッキ枚数 | 1枚 |
| タイプ | 装備（equipment） |
| 効果 | 伐採時、森の入り口で確実に持ち帰れる木材が 1本 → 2本 になる |

## ルール

### 装備について
- 斧は手札に持ち続けることで**永続的に効果を発揮**する装備カード。
- 伐採アクションを選ぶたびに自動的に適用される。

### 使用効果
- 伐採アクションを選んだとき、**森の入り口で安全に持ち帰れる木材が2本**になる。
- 通常はいかだトラック +1 → 斧装備時はいかだトラック **+2**（入り口分）。
- 森の奥に進む/進まないの選択は通常通り行える。
- 奥に進んだ場合の追加木材（1〜5本宣言）は変わらない。

### 蛇に噛まれた場合
- 蛇に噛まれたとき、入り口の2本分のみ有効（奥の追加分は無効）は通常と同じ。

### 脱落時の処理
- 斧を持ったプレイヤーがゲームから脱落した場合、斧は**捨て札**となる。
- 他のプレイヤーに引き継がれることはない。

## 通常の伐採との比較

| フェーズ | 通常 | 斧装備時 |
|---------|------|---------|
| 入り口の確保 | いかだトラック +1 | いかだトラック **+2** |
| 奥へ進む（成功） | 宣言本数追加 | 同じ |
| 奥へ進む（噛まれた） | 入り口分のみ（+1） | 入り口分のみ（+2） |

## 使用タイミング（実装予定）

装備しているだけで自動適用。伐採アクション開始時に斧の有無を確認し、  
持っていれば `RaftAction.GUARANTEED` を 2 として処理する（または保持者の保証本数を動的に算出する）。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
