# 目覚まし時計 (Alarm Clock)

## 概要
難破船カードの1種。次のラウンドのリーダーを自由に指定できるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 目覚まし時計 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 次のラウンドのリーダーを任意のプレイヤーに指定する |

## ルール

### 使用効果
- 使用したプレイヤーが、**次のラウンドのリーダーを任意に指定**する。
- 通常のリーダーローテーション（順番制）を上書きする。

### マーカーの設置
- 指定したプレイヤーの前に**次のリーダーを示す目印**を置く。
- リーダーカードが実際にその人の前に移動するまで、目印は残り続ける。
- Web実装では「次のリーダー」バッジをプレイヤーカードに表示する。

### ラウンド開始時の処理
- 次のラウンド開始時、通常のローテーションの代わりに指定したプレイヤーがリーダーになる。
- その後のローテーションは指定されたプレイヤーから再開する（通常順序に戻る）。

## 通常ローテーションとの比較

| 項目 | 通常 | 目覚まし時計使用時 |
|------|------|----------------|
| 次のリーダー | 現リーダーの次の番号 | 任意のプレイヤー |
| 以降のローテーション | 順番通り | 指定プレイヤーから再開 |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
使用後 `G.nextLeader` に指定プレイヤーのインデックスをセットし、  
次のラウンド開始時に `Leader.current = G.nextLeader` として反映する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
