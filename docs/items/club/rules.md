# 棍棒 (Club)

## 概要
難破船カードの1種。投票時の票を常に2票分にする装備カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 棍棒 |
| デッキ枚数 | 1枚 |
| タイプ | 装備（equipment） |
| 効果 | 所持している間、自分が投じる票は常に2票分の価値を持つ |

## ルール

### 装備について
- 棍棒は手札に持ち続けることで**永続的に使える**装備カード。
- 使用のたびに捨てるのではなく、持っている限り毎回の投票に適用される。

### 使用効果
- 投票フェーズで自分が票を投じると、その票は**2票分**としてカウントされる。
- 対象プレイヤーへの得票数に +2 される（通常は +1）。

### 脱落時の処理
- 棍棒を持ったプレイヤーがゲームから脱落した場合、棍棒は**捨て札**となる。
- 他のプレイヤーに引き継がれることはない。

## 他の投票系カードとの相互作用

| カード | 棍棒との組み合わせ |
|--------|-----------------|
| 錆びたナイフ | 自分への票を1票無効化（棍棒の効果には干渉しない） |
| 腐食した銃 | 指定相手への強制票を2票分追加（棍棒は自分の投票のみに適用） |
| ほら貝 | 棍棒所持者の票を受けても免疫効果は有効 |

## 使用タイミング（実装予定）

装備しているだけで自動適用。投票Step2で票を集計する際、  
棍棒所持者の票を `voteWeight = 2` として処理する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
