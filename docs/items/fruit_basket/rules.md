# フルーツバスケット (Fruit Basket)

## 概要
難破船カードの1種。そのラウンドの食料・水の消費問題を一時的に解決する特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | フルーツバスケット |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 使用したラウンドの食料・水を全員分確保扱いにする |

## ルール

### 使用効果
- 使用したラウンドは **食料・水ともに全員分が満ち足りている** とみなす。
- そのラウンドの消費フェーズで不足が発生しない（投票・ゲームオーバーにならない）。

### ラウンド終了時
- ラウンド終了時に **食料と水を両方とも 0 にリセット** する。
  （通常の「人数分を引く」消費処理の代わりに行われる）

### 脱出への使用不可
- このカードを使用したラウンドは、脱出条件（食料・水の備蓄確認）として **使用できない**。
- ラウンド終了後に食料・水が 0 になるため、脱出条件を自然に満たせない。

## 通常ラウンドとの比較

| 項目 | 通常ラウンド | フルーツバスケット使用時 |
|------|------------|----------------------|
| 消費処理 | 食料・水 -= 人数 | スキップ |
| 不足時の投票 | あり | なし |
| ラウンド終了後の食料 | 消費後の値 | 0 |
| ラウンド終了後の水 | 消費後の値 | 0 |
| 脱出条件チェック | 有効 | 無効（0になるため） |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
使用後は `G.fruitBasketThisRound = true` フラグを立て、ラウンド終了処理で判定する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
