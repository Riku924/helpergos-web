# 濁った水 (Muddy Water)

## 概要
難破船カードの1種。飲料水として使えるが、飲んだ瞬間に麻痺する危険なカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 濁った水 |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 水 +1 ＋ 使用したプレイヤーが即座に麻痺 |

## ルール

### 使用効果
- **水を1つ** 共有プールに追加する（1人分の飲み水）。
- 使用したプレイヤーは**即座に麻痺**する。
  - 麻痺の効果は通常と同じ：次ラウンドのアクションフェイズをスキップ。

### 使用制限
- **サバイバルトラックの回復には使えない**。
  - そのままの状態（未浄化）では脱出のための備蓄水として計上できない。
  - 水リソースには加算されるが、脱出条件の判定には使用不可とする。
  - ※ 実装上の詳細は脱出条件フェーズの実装時に定義予定。

## 麻痺との関係

| 項目 | 蛇に噛まれた場合 | 濁った水を飲んだ場合 |
|------|---------------|------------------|
| 麻痺の発生 | 伐採で黒玉を引く | カード使用時に即時 |
| 効果 | 次ラウンドのアクションスキップ | 同じ |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
使用後、`Paralysis.inflict(playerIdx, currentRound)` を呼び出して麻痺を付与する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
