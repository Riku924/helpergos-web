# 抗毒血清 (Antidote Serum)

## 概要
難破船カードの1種。蛇に噛まれた際に麻痺を防ぐリアクションカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 抗毒血清 |
| デッキ枚数 | 1枚 |
| タイプ | リアクション（reaction） |
| 効果 | 伐採中に蛇に噛まれた際、麻痺を無効化する（ただし追加木材は得られない） |
| 使用タイミング | 伐採で黒い玉を引いた直後（噛まれた瞬間） |

## ルール

### 発動条件
- **事前に手札にある**必要がある（後から使うことはできない）。
- 伐採アクションで奥に進み、**黒い玉を引いた（蛇に噛まれた）とき**に使用を宣言できる。

### 使用効果
- **麻痺を無効化**する（次ラウンドのアクションフェーズをスキップしなくてよい）。
- ただし、**奥で集めようとした追加木材は得られない**。
  - 入り口で確保した1本分（いかだトラック +1）のみ有効。

### トレードオフ

| 項目 | 蛇に噛まれた（通常） | 抗毒血清使用時 |
|------|-----------------|------------|
| 麻痺 | **あり**（次ラウンドスキップ） | **なし** |
| 入り口の木材（+1） | 有効 | 有効 |
| 奥の追加木材 | 無効（噛まれたため） | **無効**（血清のコスト） |

### カードの消費
- 使用後は手札から捨てる（1回限り）。
- 使用しなかった場合（噛まれなかった場合）は手札に残る。

## 使用タイミング（実装予定）

伐採モーダルの「結果表示（Step3）」で黒い玉が出た際に、  
手札に抗毒血清がある場合のみ「抗毒血清を使う」ボタンを表示する。  
使用を選択すると麻痺を付与せず、追加木材のトラック進行もスキップする。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
