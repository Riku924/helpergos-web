# マッチ箱 (Matchbox)

## 概要
難破船カードの1種。「濁った水」または「腐った魚」を安全に使えるようにする補助カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | マッチ箱 |
| デッキ枚数 | 1枚 |
| タイプ | 修飾効果（modifier） |
| 対象カード | 濁った水 / 腐った魚（どちらか1枚） |

## ルール

### 使用方法
- 手札に「濁った水」または「腐った魚」がある場合に使用できる。
- マッチ箱と対象カードを**同時に使用する**（両方とも手札から消費される）。

### 使用効果
対象カードの効果が以下のように変化する。

| 項目 | 通常使用 | マッチ箱と組み合わせ |
|------|---------|------------------|
| リソース獲得 | 水+1 / 食料+1 | 同じ |
| 麻痺 | **あり** | **なし** |
| 脱出備蓄への計上 | **不可** | **可能** |

### 使用制限
- 対象カード（濁った水 / 腐った魚）が手札にない場合は使用できない。
- 1回の使用でどちらか1枚にしか適用できない。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
アイテムUIで「マッチ箱」を選択すると、組み合わせ対象カードの選択画面を表示する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
