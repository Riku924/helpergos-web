# サンドウィッチ (Sandwich)

## 概要
難破船カードの1種。1人分の食料を補給できる。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | サンドウィッチ |
| デッキ枚数 | 7枚 |
| タイプ | 即時効果（instant） |
| 効果 | 食料 +1 |

## ルール

- 「船あさり」アクションで引いた場合、手札に加える。
- 手札から使用することで **食料を1つ** 共有プールに追加する。
- 「1人分の食料」= 食料リソース +1 として扱う。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
