# 振り子 (Pendulum)

## 概要
難破船カードの1種。他のプレイヤーのアクションを強制的に指定できる割り込みカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 振り子 |
| デッキ枚数 | 1枚 |
| タイプ | リアクション（reaction） |
| 効果 | 他の誰かのアクション開始前に使い、そのアクションを強制指定する |
| 使用タイミング | 他プレイヤーのアクション開始前（割り込み） |

## ルール

### 使用タイミング
- 自分の手番ではなく、**他のプレイヤーのアクション開始直前**に使用できる。
- アクションボタンが押される前に「振り子を使う」と宣言して発動する。

### 使用効果
- 使用者が以下の4つのアクションから1つを選び、対象プレイヤーに強制する。
  - 🐟 釣り
  - 💧 水汲み
  - 🪵 伐採
  - ⚓ 船あさり
- 対象プレイヤーはそのアクション以外を選べない。

### 制限
- 自分自身のアクションには使用できない（対象は他のプレイヤーのみ）。
- 1回使用したら捨てる（消耗品）。

## 通常アクションとの違い

| 項目 | 通常 | 振り子使用時 |
|------|------|-----------|
| アクション選択者 | 本人 | 振り子の使用者 |
| 対象 | 自分 | 他プレイヤー |
| 発動タイミング | 手番中 | 他プレイヤーの手番開始前 |

## 使用タイミング（実装予定）

各プレイヤーの手番開始時に「振り子を使う」ボタンを表示する（手札に振り子がある他プレイヤーに対して）。  
発動すると強制アクションを選択するモーダルが開き、対象プレイヤーは指定されたアクションのみ実行できる。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
