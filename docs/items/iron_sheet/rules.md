# トタン板 (Corrugated Iron Sheet)

## 概要
難破船カードの1種。銃による射撃を1発だけ防ぐリアクションカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | トタン板 |
| デッキ枚数 | 2枚 |
| タイプ | リアクション（reaction） |
| 効果 | 銃で狙われたとき、弾丸1発を防いで排除を無効化する |
| 使用タイミング | 銃で自分が狙われた瞬間（射撃後） |

## ルール

### 使用タイミング
- 他のプレイヤーが銃を使って**自分を排除しようとした瞬間**に使用を宣言する。
- 使用後は手札から捨てる（1回限り）。

### 使用効果
- 銃による排除を**無効化**する。
- 弾丸は消費されたままとなる（撃った側は弾丸を1枚失う）。
- 自分はゲームに留まる。

### 制限
- 銃以外の排除（投票など）には使用できない。
- 1枚で防げるのは弾丸**1発分**のみ。

## 使用タイミング（実装予定）

銃使用モーダルで対象プレイヤーが確定した際、  
対象プレイヤーの手札にトタン板があれば「トタン板を使う」ボタンを表示する。  
発動すると排除を無効化し、弾丸のみ消費させる。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
