# 望遠鏡 (Telescope)

## 概要
難破船カードの1種。任意の1人の手札をすべてこっそり確認できるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 望遠鏡 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 任意の1人を選び、その人の手札全てを秘密裏に確認する |

## ルール

### 使用効果
- 生存プレイヤーの中から**1人を選ぶ**（自分以外）。
- 選んだプレイヤーの**手札全てを使用者だけが確認する**。
- 対象プレイヤーには確認されたことを知らせなくてよい（秘密）。
- 使用後は手札から捨てる（1回限り）。

### 制限
- 自分自身は対象に選べない。
- 手札が0枚のプレイヤーを選んでも何も見えない。

## 懐中時計・気圧計との対比

| カード | 確認対象 | 枚数 |
|--------|---------|------|
| 懐中時計 | 難破船カード山札の上から | 3枚 |
| 気圧計   | 天候カード山札の上から | 2枚 |
| 望遠鏡   | 任意プレイヤーの手札 | 全枚 |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
対象プレイヤーを選択後、「他のプレイヤーは目を閉じてください」の秘密モーダルで  
`Hand.get(targetIdx)` の内容を全て表示する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
