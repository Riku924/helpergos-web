# 懐中時計 (Pocket Watch)

## 概要
難破船カードの1種。山札の上から3枚をこっそり確認できるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 懐中時計 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 難破船カード山札の上から3枚を秘密裏に確認し、同じ順番で戻す |

## ルール

### 使用効果
- 難破船カード山札の**上から3枚の内容**を使用者だけがこっそり確認する。
- 確認後、**元の重ね順のまま**山札に戻す（カードの順番は変更しない）。
- 他のプレイヤーにはカードの内容を見せてはいけない。

### 制限
- 山札が3枚未満の場合は残り枚数分だけ確認する。
- カードを引く・並び替えることはできない（確認のみ）。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
Web実装では `Shipwreck.peekTop(3)` で上位3枚を取得し、使用者のみが見られる秘密モーダルで表示する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
