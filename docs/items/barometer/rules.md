# 気圧計 (Barometer)

## 概要
難破船カードの1種。天候カード山札の上から2枚をこっそり確認できるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 気圧計 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 天候カード山札の上から2枚を秘密裏に確認し、同じ順番で戻す |

## ルール

### 使用効果
- 天候カード山札の**上から2枚の内容**を使用者だけがこっそり確認する。
- 確認後、**元の重ね順のまま**山札に戻す（カードの順番は変更しない）。
- 他のプレイヤーにはカードの内容を見せてはいけない。

### 制限
- 山札が2枚未満の場合は残り枚数分だけ確認する。
- カードを引く・並び替えることはできない（確認のみ）。

## 懐中時計との対比

| 項目 | 懐中時計 | 気圧計 |
|------|---------|-------|
| 対象の山札 | 難破船カード山札 | 天候カード山札 |
| 確認枚数 | 3枚 | 2枚 |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
Web実装では `Weather.peekTop(2)` で上位2枚を取得し、使用者のみが見られる秘密モーダルで表示する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
