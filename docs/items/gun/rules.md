# 銃 (Gun)

## 概要
難破船カードの1種。弾丸があれば誰かを即座にゲームから排除できる装備カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 銃 |
| デッキ枚数 | 3枚 |
| タイプ | 装備（equipment） |
| 効果 | 弾丸を持っている場合、任意の1人をゲームから排除する |
| 使用条件 | 手札に「弾丸」カードが必要 |

## ルール

### 装備について
- 銃は手札に持ち続けることで**永続的に使用可能**な装備カード。
- 使用のたびに手札から捨てるのではなく、**弾丸1発を消費**して使う。
- 弾丸がなくなれば使用できないが、銃自体は手札に残る。

### 使用効果
- 弾丸を1枚消費し、任意の1人を選んでゲームから**永久に排除**する。
- 排除されたプレイヤーはその後のターン・消費・脱出判定から除外される。
- 投票フェーズを経ずに排除できる（抵抗手段なし）。

### 脱落時の処理
- 銃を持ったプレイヤーがゲームから脱落した場合、**銃はそのプレイヤーの手札として処理**される。
- 他のプレイヤーに引き継がれることはない。

## 依存カード
- **弾丸**（未追加）: 銃を使用するために必要。弾丸が手札にない場合、銃は使用できない。

## 「投票による脱落」との違い

| 項目 | 投票による脱落 | 銃による排除 |
|------|-------------|-----------|
| 発動条件 | 資源不足時 | 弾丸所持時、任意のタイミング |
| 対象 | 投票で決定 | 使用者が自由に選択 |
| 抵抗 | 投票系アイテムで防御可能 | 防御手段なし |
| 人数制限 | 不足分を補う人数 | 1人 |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
手札に弾丸がある場合のみ発動可。弾丸1枚を消費し、対象プレイヤーを選択する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
