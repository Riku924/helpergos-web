# 人肉バーベキューセット (Human BBQ Set)

## 概要
難破船カードの1種。そのラウンドで死亡した人数に応じて食料を獲得する特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 人肉バーベキューセット |
| デッキ枚数 | 1枚 |
| タイプ | ラウンド終了時効果（round_end） |
| 効果 | 食料 += そのラウンドの死亡者数 × 2 |

## ルール

### 使用タイミング
- **ラウンド終了時**に使用する（アクションフェーズのアクション代わりではない）。
- そのラウンドに投票などで死亡したプレイヤーが出た後に発動できる。

### 効果計算
- `獲得食料 = そのラウンドで死亡した人数 × 2`
- 死亡者がいない（0人）ラウンドに使用しても食料は増えない（0 × 2 = 0）。

### 使用例

| そのラウンドの死亡者数 | 獲得食料 |
|-------------------|---------|
| 0人 | 0 |
| 1人 | 2 |
| 2人 | 4 |
| 3人 | 6 |

## 実装メモ（実装予定）

- ラウンド内の死亡者数を `G.deathsThisRound` として管理する。
- 投票で脱落したプレイヤーが出るたびにインクリメント。
- ラウンド終了時にこのカードが手札にある場合、使用選択肢を提示する。
- 使用後 `G.food += G.deathsThisRound * 2`、`G.deathsThisRound` をリセット。
- ※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
