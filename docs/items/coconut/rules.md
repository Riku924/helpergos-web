# ココナッツの実 (Coconut)

## 概要
難破船カードの1種。3人分の水を一度に補給できるカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | ココナッツの実 |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 水 +3 |

## ルール

- 手札から使用することで **水を3つ** 共有プールに追加する。
- 「3人分の水」= 水リソース +3 として扱う。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
