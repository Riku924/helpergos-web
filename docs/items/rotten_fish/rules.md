# 腐った魚 (Rotten Fish)

## 概要
難破船カードの1種。食料として使えるが、食べた瞬間に麻痺する危険なカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 腐った魚 |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 食料 +1 ＋ 使用したプレイヤーが即座に麻痺 |

## ルール

### 使用効果
- **食料を1つ** 共有プールに追加する（1人分の食料）。
- 使用したプレイヤーは**即座に麻痺**する。
  - 麻痺の効果は通常と同じ：次ラウンドのアクションフェイズをスキップ。

### 使用制限
- **サバイバルトラックの回復には使えない**。
  - そのままの状態（未処理）では脱出のための備蓄食料として計上できない。
  - 食料リソースには加算されるが、脱出条件の判定には使用不可とする。
  - ※ 実装上の詳細は脱出条件フェーズの実装時に定義予定。

## 「濁った水」との対比

| 項目 | 濁った水 | 腐った魚 |
|------|---------|---------|
| 追加リソース | 水 +1 | 食料 +1 |
| 麻痺 | あり | あり |
| 脱出備蓄への使用 | 不可 | 不可 |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
使用後、`Paralysis.inflict(playerIdx, currentRound)` を呼び出して麻痺を付与する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
