# 釣竿 (Fishing Rod)

## 概要
難破船カードの1種。装備している間、釣りアクションを2回行えるようになる装備カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 釣竿 |
| デッキ枚数 | 1枚 |
| タイプ | 装備（equipment） |
| 効果 | 釣りアクション時、2回分の食料を獲得する |

## ルール

### 装備について
- 釣竿は手札に持ち続けることで**永続的に効果を発揮**する装備カード。
- 使用のたびに捨てるのではなく、持っている限り毎回の釣りに適用される。

### 使用効果
- 自分の手番で釣りアクションを選んだとき、**釣りを2回分**行える。
- 獲得食料 = 1回目の結果 ＋ 2回目の結果

### 脱落時の処理
- 釣竿を持ったプレイヤーがゲームから脱落した場合、釣竿はそのプレイヤーの手札として処理される（引き継ぎなし）。

## 使用タイミング（実装予定）

装備しているだけで自動適用。釣りアクション選択時に釣竿の有無を確認し、  
持っていれば `FoodAction.fish()` を2回呼び出してその合計を食料に加算する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
