# 木の板 (Wood Plank)

## 概要
難破船カードの1種。即座にいかだを1枚完成させる特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 木の板 |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 完成いかだ +1（いかだトラックの位置は変わらない） |

## ルール

### 使用効果
- 使用した瞬間に **いかだカードを1枚** ゲームボードに置く。
- いかだ1つ完成と同義。
- **いかだトラック（木製ディスクの位置）はそのまま維持される。**

### 脱出投票での使用
- 最終的な脱出投票フェーズ（いかだ枚数が足りず誰かが脱落しなければならない状況）で使用すると、**自分が脱落せずに済む。**
- ※ 脱出投票は未実装のため、この効果は今後のルール追加で実装予定。

## 通常のいかだ完成との違い

| 項目 | 伐採でのトラック到達 | 木の板の使用 |
|------|-----------------|-----------|
| いかだトラック位置 | 6マス → 0にリセット | 変化なし |
| 完成いかだ数 | +1 | +1 |
