# 水晶玉 (Crystal Ball)

## 概要
難破船カードの1種。投票フェーズで常に最後に投票できる装備カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 水晶玉 |
| デッキ枚数 | 1枚 |
| タイプ | 装備（equipment） |
| 効果 | 投票フェーズで、常に最後に投票する |

## ルール

### 装備について
- 水晶玉は手札に持ち続けることで**永続的に使える**装備カード。
- 投票が発生するたびに自動的に適用される。

### 使用効果
- 投票フェーズの順番に関わらず、水晶玉の所持者は**必ず最後に投票する**。
- 他の全員が投票し終えた後に、所持者の投票番が来る。
- これにより、全員の投票先を見てから自分の票を決められる。

### 脱落時の処理
- 水晶玉を持ったプレイヤーがゲームから脱落した場合、水晶玉は**捨て札**となる。
- 他のプレイヤーに引き継がれることはない。

## 使用タイミング（実装予定）

装備しているだけで自動適用。投票フェーズの `voterQueue` を構築する際に、  
水晶玉所持者を末尾に移動させる処理を追加する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
