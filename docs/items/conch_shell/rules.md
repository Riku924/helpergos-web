# ほら貝 (Conch Shell)

## 概要
難破船カードの1種。そのラウンドの投票で脱落を免れるリアクションカード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | ほら貝 |
| デッキ枚数 | 1枚 |
| タイプ | リアクション（reaction） |
| 効果 | そのラウンドの投票で脱落しない。最多票でも再投票になる。 |
| 使用タイミング | 投票フェーズ中、または投票結果が出た後でも使用可 |

## ルール

### 使用効果
- 使用したプレイヤーは**そのラウンドの投票で脱落しない**。
- 最多票を獲得した場合でも脱落せず、**そのプレイヤーを除いた残りで再投票**を行う。
- 使用後は手札から捨てる（1回限り）。

### 使用タイミング
- 投票フェーズ中（自分の番が来る前）でも使用できる。
- **投票が終わって結果が出た後でも**使用可能（事後発動）。

### 再投票のルール
- 再投票の対象は「ほら貝を使ったプレイヤー以外の生存者全員」。
- 再投票でも最多票のプレイヤーが脱落する（同数はリーダー決定）。
- 再投票時にほら貝を使ったプレイヤーへの票は無効。

## 通常の投票との比較

| 状況 | 通常 | ほら貝使用時 |
|------|------|-----------|
| 最多票を取った | 脱落 | **再投票**（使用者を除く） |
| 最多票でない | 脱落なし | 同じく脱落なし |
| 使用タイミング | — | 投票中・投票後どちらでも可 |

## 使用タイミング（実装予定）

投票モーダルのStep4（結果表示）で最多票が確定した際、  
対象プレイヤーの手札にほら貝があれば「ほら貝を使う」ボタンを表示する。  
発動すると使用者を除いた再投票フローに移行する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
