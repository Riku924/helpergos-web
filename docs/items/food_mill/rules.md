# フードミル (Food Mill)

## 概要
難破船カードの1種。食料を水に変換できる特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | フードミル |
| デッキ枚数 | 1枚 |
| タイプ | 即時効果（instant） |
| 効果 | 食料 -2 → 水 +2（変換） |

## ルール

- 使用時、共有プールの **食料を2つ消費** し、**水を2つ獲得** する。
- 食料が2つ未満の場合は使用できない。

## 注意事項

- 食料と水は同時に変動する（食料が先に減り、その後水が増える）。
- いかだトラック・完成いかだには影響しない。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
