# 睡眠薬 (Sleeping Pills)

## 概要
難破船カードの1種。他のプレイヤーの手札を裏向きのまま盗む特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 睡眠薬 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | 指定した最大3人から手札を1枚ずつ盗む（裏向き） |

## ルール

### 使用方法
- 使用するプレイヤーが **1〜3人を選択** する。
- 選んだ各プレイヤーの手札から **裏向きのまま1枚ずつ** 無作為に取る。
- 盗んだカードは自分の手札に加わる（中身は後で確認できる）。

### 重要なルール
- **反撃する間を与えない**: 対象プレイヤーはカードを守る手段がない。
- **裏向きで取る**: 使用者は盗んだカードの中身を事前に知ることができない（ランダム選出）。
- 手札が0枚のプレイヤーは対象に選べない（盗めるカードがないため）。
- 自分自身は対象に選べない。

### 盗める人数
- 最大3人まで（1人・2人でも使用可能）。

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
アイテムUIで対象プレイヤーを最大3人まで選択し、それぞれの手札から1枚をランダムに移動する。  
盗んだカードの内容は使用者のみ後から確認可能（他プレイヤーには枚数のみ公開）。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
