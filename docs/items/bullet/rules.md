# 弾丸 (Bullet)

## 概要
難破船カードの1種。銃と組み合わせて使う消耗品カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | 弾丸 |
| デッキ枚数 | 6枚 |
| タイプ | 弾薬（ammo） |
| 効果 | 銃と組み合わせて任意の1人をゲームから排除する |
| 使用条件 | 手札に「銃」カードが必要 |

## ルール

- 弾丸単体では使用できない。**手札に銃がある場合のみ**発動可能。
- 使用時、弾丸1枚を消費して銃を発射し、任意の1人をゲームから排除する。
- 銃は消費されず手札に残る（弾丸のみ捨てる）。
- 弾丸をすべて使い切っても銃は手元に残るが、発射はできない。

## 銃との関係

| 消費されるもの | 残るもの |
|-------------|---------|
| 弾丸（1枚） | 銃（手札に残る） |

## 使用タイミング（実装予定）

自分の手番にアクションの代わりとして使用する。  
手札に銃がある場合のみ選択可能。弾丸を消費し、対象プレイヤーを選択する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
