# まじない人形 (Voodoo Doll)

## 概要
難破船カードの1種。死亡したプレイヤーを1人蘇らせることができる特殊カード。

## カード情報

| 項目 | 内容 |
|------|------|
| カード名 | まじない人形 |
| デッキ枚数 | 1枚 |
| タイプ | 特殊効果（special） |
| 効果 | ラウンド開始時に、死亡者の中から1人を選んで蘇らせる |
| 使用タイミング | ラウンドの初め（天候フェーズより前） |

## ルール

### 使用タイミング
- **ラウンドの初め**、天候カードをめくる前に使用を宣言する。
- 死亡者がいない場合は使用できない。

### 使用効果
- 死亡者（投票・銃などで脱落したプレイヤー）の中から**1人を選んで蘇らせる**。
- 蘇ったプレイヤーは即座にそのラウンドから復帰し、ターン順に加わる。
- 使用後は手札から捨てる（1回限り）。

### 蘇生後のステータス
- 蘇ったプレイヤーは通常の生存者として扱われる。
- 脱落時に持っていた手札はそのまま引き継ぐ。

## 使用タイミング（実装予定）

ラウンド開始処理（天候フェーズ前）に「まじない人形を使う」選択肢を表示する。  
手札にまじない人形があるプレイヤーがいる場合のみ提示。  
発動すると死亡者一覧から蘇生対象を選択するモーダルを表示し、  
`G.survivors` に復帰させ `G.turnOrder` を再構築する。  
※ アイテム使用UIは未実装のため、現在は手札に保持されるのみ。
