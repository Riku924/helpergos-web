# 伐採・いかだ建造 (Raft Building)

## 概要
木を伐採していかだの材料を集めるアクション。  
毒蛇が生息する危険な森へ踏み込む必要がある。

## アクションの流れ

```
① 伐採を宣言
    └→ 森の入り口の木材1本を確実に確保
       いかだトラックを1マス進める

② 森の奥へ進むか選択
    ├→【やめる】そのままターン終了
    └→【進む】  ③へ

③ 追加で集める本数を宣言（1〜5本）
    └→ 宣言した数と同じ数の玉を袋から引く

④ 結果判定
    ├→【全て白】成功: 宣言本数だけいかだトラックを進める
    └→【黒あり】失敗: 毒蛇に噛まれ、次ラウンドのアクションフェイズまで麻痺
               ※ 白い玉をいくつ引いていてもトラックは進まない
               ※ 入り口の1マスのみ有効

⑤ 取り出した玉はすべて袋に戻す
```

## 重要ルール
- 入り口の1本は **必ず確保できる**（リスクなし）。
- 奥に進む場合は **追加分を宣言してから**  玉を引く（事後変更不可）。
- いかだトラックが6マス進むごとにいかだ1枚完成（→ [いかだトラック](../rafttrack/rules.md) 参照）。
