# 水汲み (Water Collection)

## 概要
そのラウンドの天候カードに示された雨量だけ水を確保するアクション。

## ルール

### 取得量
- 天候カードの雨量 = そのプレイヤーが得る水の量。
- 雨量が 0（快晴）のときに水汲みを選んでも水は 0 しか得られない。

### 制約
- 天候カードがめくられる前は選択できない。
- 1ターンに選べるアクションは1つだけ（水汲み・釣り・伐採から1択）。

### 具体例
| 天候カード | 取得量 |
|-----------|--------|
| ☀️ 快晴（0） | 水 +0 |
| 🌦️ 小雨（1） | 水 +1 |
| 🌧️ 雨（2）   | 水 +2 |
| ⛈️ 大雨（3） | 水 +3 |
