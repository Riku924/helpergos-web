# 投票ルール（実装済み）

## 発動条件
ラウンド終了時に `食料 < 生存者数` または `水 < 生存者数` の場合に投票フェーズへ移行。

## フロー

```
ラウンド終了
  → 資源不足チェック（消費前）
    → 不足なし: 通常ラウンド終了（消費 → 次ラウンド）
    → 不足あり: 投票フェーズへ
      1. チャット相談バナーを表示（チャットで議論）
      2. 「投票を開始する」を押すと秘密投票モーダル
      3. 各プレイヤーが順番に投票（pass-the-device）
      4. 集計 → 最多票プレイヤーを脱落
      5. 同票 → 生存者配列の先頭がタイブレーク
      6. 資源が充足するまで繰り返し（再投票）
      7. 全員脱落 → ゲームオーバー
      8. 充足 → 消費 → 次ラウンド
```

## 手札カードとの連携

| カード | 効果 | 種別 |
|--------|------|------|
| ほら貝（vote_immunity） | 投票モーダル内で使用 → 自分をこのラウンドの脱落から守る | 反応（Hand） |
| 棍棒（double_vote） | 自分の票が2票分 | 装備（Equipped） |
| 水晶玉（vote_last） | 全員の後に最後に投票 | 装備（Equipped） |

## 実装ファイル

- `features/voting/voting.js` — Voting モジュール（票管理・集計）
- `index.html` — 投票フェーズUI・ロジック（`startVotingPhase`, `startPrivateVoting`, `confirmVoteResult` 等）

## 既存機能との差異（原文ルールとの違い）

| 項目 | 原文 | 本実装 |
|------|------|--------|
| 投票方式 | 同時投票 | 順番に秘密投票（pass-the-device） |
| 同票処理 | 記載なし | 生存者配列の先頭プレイヤーが脱落 |
