# リーダー (Leader)

## 概要
各ラウンドの進行役。ゲーム開始時にランダムで最初のリーダーが決まり、  
以降は毎ラウンド終了ごとに次のプレイヤーへ移っていく。

## ルール

### 初期選出
- ゲーム開始時、3人の中からランダムで1人がリーダーに選ばれる。

### ターン順
- そのラウンドはリーダーから順に手番を行う。
  - 例: リーダーがプレイヤー2 の場合 → プレイヤー2 → プレイヤー3 → プレイヤー1

### ローテーション
- 1ラウンドが終わると、リーダーは次のプレイヤー（番号順）へ移る。
  - プレイヤー3 → プレイヤー1 へ巻き戻る。

### リーダーの権限
- ラウンド開始時に天候カードをめくる（天候フェイズ参照）。
- 討論・交渉・脅しは全員いつでも自由に行える。
