# 天候カード (Weather Card)

## 概要
ラウンドの最初にリーダーが1枚めくるカード。  
そのラウンドに集められる水の量（雨量）を決定する。

## ルール

### タイミング
- 毎ラウンドの最初（アクションフェイズの前）にリーダーが1枚めくる。
- カードをめくるまでアクションは実行できない。

### デッキ構成（全10枚）
| 雨量 | 枚数 | アイコン | 説明 |
|------|------|----------|------|
| 0    | 2枚  | ☀️ 快晴   | 雨なし。水汲みをしても水が得られない |
| 1    | 3枚  | 🌦️ 小雨   | 水 1 を取得できる |
| 2    | 3枚  | 🌧️ 雨     | 水 2 を取得できる |
| 3    | 2枚  | ⛈️ 大雨   | 水 3 を取得できる |

### デッキ切れ
- 10枚すべて使い切ったら自動的にシャッフルして再利用する。
