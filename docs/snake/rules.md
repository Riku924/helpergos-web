# 毒蛇の玉袋 (Snake Bag)

## 概要
伐採で森の奥へ進んだ際にリスクを決定する仕組み。  
袋から玉を引き、黒い玉が含まれていたら毒蛇に噛まれる。

## 袋の構成

| 玉の種類 | 数 |
|----------|----|
| ⚪ 白い玉 | 7個 |
| ⚫ 黒い玉 | 3個 |
| **合計**  | **10個** |

> ※ 黒い玉の数はルールブックに記載がない場合はこのデフォルト値を使用。

## 引き方
- 宣言した本数（1〜5）と同じ数の玉を一度に引く。
- 引いた玉に黒が **1つでも含まれていた** → 噛まれた判定。
- 引いた玉は結果に関わらずすべて袋に戻す。

## 安全確率（白7・黒3・10個の場合）

| 宣言本数 | 安全確率 |
|----------|----------|
| 1本      | 70%      |
| 2本      | 47%      |
| 3本      | 29%      |
| 4本      | 17%      |
| 5本      | 8%       |
