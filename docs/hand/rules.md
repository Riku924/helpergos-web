# 手札管理 (Hand)

## 概要
各プレイヤーが持つ秘密の手札。  
枚数は全員に公開されるが、カードの内容は本人だけが知る。

## ルール

### カード使用のタイミング
- 難破船カードの使用は**アクションに含まれない**。
- **いつでも使用できる**。自分の手番・他の人の手番・投票後など、タイミングを問わない。
- カードを使ってもアクション権は消費されない。

### カードの譲渡
- 他のプレイヤーにカードを**渡すことができる**。
- 渡す際も受け取る際も、他のプレイヤーには見せてはいけない（秘密を保持）。

### カードの開示
- 「自分はこのカードを持っている」と**口頭で伝えることは可能**。
- しかし、いついかなる時も**カード現物を見せてはいけない**（嘘をついてもよい）。

### 秘密の保持
- 手札の内容（カード名・効果）を他のプレイヤーに見せてはいけない。
- 同じ画面を共有している場合、カードを見るときは他のプレイヤーが目を閉じるなどして対応する。
- 枚数のみ全員に公開される。

### カードの追加
- ゲーム開始時に人数に応じた枚数が配られる（3〜8人: 4枚 / 9〜12人: 3枚）。
- ゲーム中は「船あさり」アクションで山札から追加取得できる。
- 他のプレイヤーから譲り受けることができる。
