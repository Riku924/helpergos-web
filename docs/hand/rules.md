# 手札管理 (Hand)

## 概要
各プレイヤーが持つ秘密の手札。  
枚数は全員に公開されるが、カードの内容は本人だけが知る。

## ルール

### 秘密の保持
- 手札の内容（カード名・効果）を他のプレイヤーに見せてはいけない。
- 同じ画面を共有している場合、カードを見るときは他のプレイヤーが目を閉じるなどして対応する。

### 枚数の公開
- 各プレイヤーが何枚の手札を持っているかは、全員に見える状態で表示される。

### カードの追加
- 現在、手札へカードを加える方法は「船あさり」アクションのみ。

## 実装上の注意（Web版）
- 「カードを見る」ボタンを押すと引いたカードが表示される。
- 他プレイヤーは画面を見ないよう促すメッセージを表示。
- OKを押すまでカード内容はモーダル内にのみ表示される。
