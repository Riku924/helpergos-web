# 永続カード（装備）ルール

## 概要
難破船カードのうち「永続的に使えるもの（equipment）」は、手番に自分で装備を宣言するまで効果が発動しない。
装備後は全プレイヤーから見える公開情報となる。

## 対象カード（type: equipment）

| カード名 | 効果 | 脱落時 |
|---------|------|--------|
| 釣竿 | 釣りアクションが2回分 | 捨て札 |
| 水筒 | 水汲みアクションが2倍 | 捨て札 |
| 斧 | 入り口の木材が2本 | 捨て札 |
| 棍棒 | 投票が常に2票分 | 捨て札 |
| 水晶玉 | 投票で常に最後 | 捨て札 |
| 銃 | 弾丸消費で対象を排除 | 捨て札 |

## ルール

### 装備の宣言
- 装備カードは**手番にアクションとして「装備する」**を宣言して初めて効果が発動する。
- 装備するまでは手札の中に秘密として保持できる。
- 装備するタイミングは自分で選べる（すぐに装備する必要はない）。

### 装備後の状態
- 装備したカードは手札から取り出され、**全プレイヤーから見える「装備エリア」**に置かれる。
- プレイヤーカードにカード名が表示される。
- 効果は装備している間ずっと有効（永続）。

### 脱落時の処理
- 各カードの「脱落時」ルールに従う（現在は全て「捨て札」）。

## 実装ファイル
- `features/equipped/equipped.js`（公開装備状態の管理）
- `features/hand/hand.js`（手札から装備へ移動）
