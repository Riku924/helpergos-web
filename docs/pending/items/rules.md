# アイテム効果（未実装）

## ルール原文（rules/17_items.md）
> 食料、水、武器、特殊効果などが存在する。

## 詳細（rules/08_action_wreckage.md からの補足）
- 「残骸を探索する（船あさり）」アクションで獲得するカードにはさまざまな種類がある
- カードの種類: 食料系・水系・武器系・特殊効果系

## 実装が必要な内容

| カード種別 | 想定効果（要定義） |
|-----------|-----------------|
| 食料カード | 食料を即時獲得 |
| 水カード | 水を即時獲得 |
| 武器カード | 投票時などに影響（要定義） |
| 特殊効果カード | ゲームルールに影響（要定義） |

## 現状
- 難破船カード自体は実装済み（10枚のプレースホルダー）
- カードを引いて手札に加える仕組みは動作中
- **カードを使う・効果を発動する仕組みが未実装**

## 実装ステータス
- ❌ 効果未実装（カード名のプレースホルダーのみ）
- カード内容・効果の定義が必要
