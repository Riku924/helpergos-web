# 投票ルール（未実装）

## ルール原文（rules/12_voting_rules.md）
> 資源不足時、相談後に同時投票を行う。

## 詳細（rules/10, 11, 01 からの補足）
- 水または食料が生存者全員分に足りない場合に発動
- プレイヤー同士で相談してから**同時投票**
- 票が最多のプレイヤーが脱落（資源消費の対象から外れる）
- 脱落により資源が成立すれば生存継続
- 資源が不足したまま全員脱落すれば全滅

## 実装が必要な内容

| 機能 | 説明 |
|------|------|
| 投票UIの表示 | 全員が一斉に投票できる画面 |
| 票の集計 | 最多票プレイヤーの特定 |
| 脱落処理 | 脱落者の生存フラグを落とし、消費人数を減らす |
| 再判定 | 脱落後も資源不足なら再投票 |
| 全滅条件 | 脱落で全員いなくなった場合のゲームオーバー |

## 実装ステータス
- ❌ 未実装
- 現在: 資源不足 → 即ゲームオーバー
