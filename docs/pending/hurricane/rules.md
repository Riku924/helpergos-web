# ハリケーンルール（未実装）

## ルール原文（rules/14_hurricane_rules.md）
> ハリケーン発生時は強制脱出判定を行う。

## 詳細（rules/03_weather_phase.md / 02_round_flow.md からの補足）
- 天候カードの中に「ハリケーン」カードが存在する
- ハリケーンカードが公開されたラウンド終了時に**強制脱出判定**を行う
- 脱出条件を満たせない場合 → そのラウンドで**全員敗北（ゲームオーバー）**
- ラウンド終了を待たずに緊急脱出を迫られる

## 実装が必要な内容

| 機能 | 説明 |
|------|------|
| ハリケーンカードの追加 | 天候デッキにハリケーンを追加 |
| ハリケーンフラグ | そのラウンドがハリケーンかどうかの状態管理 |
| 強制脱出判定 | ラウンド終了時に脱出条件を満たしているか確認 |
| 不成立時のゲームオーバー | 条件未達の場合は全員敗北 |

## 天候デッキへの影響
現在の天候デッキ（雨量 0〜3 の10枚）に、  
ハリケーンカードを何枚か追加する必要がある（枚数は要定義）。
