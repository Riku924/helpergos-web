# 脱出条件 (Escape Condition)

## 概要
全員がいかだで島を脱出するための条件。

## 脱出条件
以下の3つをすべて満たしたとき、脱出成功となる。

| リソース | 必要量 |
|----------|--------|
| 食料     | 3 以上 |
| 水       | 3 以上 |
| いかだ   | 3 以上 |

## チェックタイミング
- 各アクション実行直後（消費フェイズより前）に判定する。

## ゲームオーバー条件
- ラウンド終了時の消費後に食料または水がマイナスになった場合。
