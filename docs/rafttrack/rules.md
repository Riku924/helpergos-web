# いかだトラック (Raft Track)

## 概要
木材を集めるごとに木製ディスクがトラック上を進み、  
6マス進むたびにいかだが1枚完成する仕組み。

## トラックの仕組み

```
[ □ □ □ □ □ □ ]  ← 0〜5 のマス
```

- 木材を1本確保するたびに1マス進む。
- **6マスに達した時点でいかだ1枚完成**。ディスクは0に戻り次のいかだへ。
- 6を超える木材を一度に取得した場合、余剰分は次のいかだのカウントに繰り越す。

## 完成したいかだ
- いかだカードの山札から1枚取り、いかだカード置き場に置く。
- **完成したいかだ1枚につき、1人が島から脱出できる**。

## 脱出条件との関係
- 3人全員が脱出するには **いかだカードが3枚以上** 必要。

## 例
| アクション           | トラック位置 | 完成枚数 |
|---------------------|------------|---------|
| 初期状態             | 0          | 0       |
| 伐採（入り口1本）     | 1          | 0       |
| 伐採（奥で3本成功）   | 4          | 0       |
| 伐採（入り口1本）     | 5          | 0       |
| 伐採（奥で3本成功）   | 2          | **1**   |  ← 5+1+3=9、9÷6=1枚完成、余り3
